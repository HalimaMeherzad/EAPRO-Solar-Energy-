☀️ EAPRO — Solar Energy Website

A modern and responsive solar energy website designed for EAPRO, focused on providing reliable and clean energy solutions for Indian homes.

The website combines a clean and modern interface with interactive components, responsive layouts, product sections, customer stories, and a solar savings calculator.

✨ Features

* Modern and clean UI/UX
* Fully responsive design
* Solar energy focused landing page
* Video-based hero section
* Product and content sections
* Interactive solar savings calculator
* Statistics and information sections
* Customer testimonials
* Clear call-to-action buttons
* Desktop, tablet, and mobile support
* Smooth visual interactions and transitions

🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Git & GitHub
* VS Code

🧮 Solar Savings Calculator

The website includes an interactive solar savings calculator that allows users to enter their current monthly electricity bill and estimate their potential savings after switching to solar energy.

The calculator provides a simple and user-friendly way to understand the possible financial benefits of solar energy.

🎯 Design Approach

The website was designed around three main principles:

Clarity

Information is presented through clear sections, typography, visual hierarchy, and concise content.

Trust

Customer stories, statistics, product information, and service-focused content help create a professional brand experience.

Simplicity

Solar energy solutions are presented in a simple and understandable way so users can quickly explore the products and their benefits.

📱 Responsive Design

The website is designed to work across different screen sizes:

* Desktop
* Tablet
* Mobile

The layout adapts to different devices while maintaining usability, readability, and visual consistency.
